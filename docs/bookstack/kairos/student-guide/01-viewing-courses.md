# Viewing courses

## What this is for

Open courses you are enrolled in and understand what appears on a course home page.

## How to do it

1. Open the Kairos dashboard.
2. Find the course under **My Courses**.
3. Select the course card.
4. Review the course progress, assignments due, quizzes, modules, announcements, and recent activity.
5. Select **All Courses** to return to the dashboard.

## Notes

- A public course preview does not give access to its learning content.
- Select **Enrol in course** only when that option is shown and you intend to join.
- Contact the course Manager if an expected course is missing.
