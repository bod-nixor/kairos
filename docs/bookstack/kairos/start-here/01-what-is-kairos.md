# What is Kairos?

## What this is for

Kairos is Nixor College's platform for courses, learning materials, assignments, quizzes, grades, rooms, and TA support.

## How to do it

1. Open [Kairos](https://kairos.nixorcorporate.com/signoff/).
2. Sign in with the login method provided to you.
3. Choose a course from **My Courses**.
4. Use the course menu to open **Home**, **Modules**, **Quizzes**, or **Assignments**.
5. Use role tools only if you are a TA, Manager, or Admin.

## Notes

- Students see learning and submission tools.
- TAs see TA and grading tools for assigned courses.
- Managers manage assigned courses.
- Admins manage platform-wide courses, accounts, and course staff.
