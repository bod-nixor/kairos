# Logging in

## What this is for

Use this page to access Kairos with Google or an Admin-invited password account.

## How to do it

1. Open [Kairos](https://kairos.nixorcorporate.com/signoff/).
2. Select the Google sign-in option for your `@nixorcollege.edu.pk` account.
3. If an Admin invited you to a password account, enter your username or email and password instead.
4. Select **Sign in with password**.

![Kairos login options](../screenshots/login.png)

## Notes

- Google is the normal login method for Nixor College accounts.
- Password login appears only when local-password accounts are enabled.
- Never share your password with another person.

## Troubleshooting

- Check that you selected the correct Google account.
- For password accounts, use **Forgot password?** if your password is not accepted.
- Contact an Admin if your role or courses are missing after login.
