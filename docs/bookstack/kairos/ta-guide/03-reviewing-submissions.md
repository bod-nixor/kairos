# Reviewing submissions

## What this is for

Open assigned submissions and review student work before grading.

## How to do it

1. Open the course.
2. Select **Grading**.
3. Choose an assignment from the assignment list.
4. Filter by status or search for a Student.
5. Select a submission from the queue.
6. Review the submitted file, text, link, attachments, and Student comment.

## Notes

- TAs see assignments and submissions available to their grading access.
- A Student's **Comment for staff** appears with the submission.
- Student private assignment notes are not visible here.
