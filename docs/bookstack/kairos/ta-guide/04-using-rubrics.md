# Using rubrics

## What this is for

Score a submission against the rubric prepared by a Manager or Admin.

## How to do it

1. Open a submission in **Grading**.
2. Review each rubric criterion.
3. Enter a score within the maximum shown for each criterion.
4. Check the calculated total.
5. Add feedback for the Student.
6. Select **Save Draft** or **Release Grade**.

## Notes

- TAs use the assigned rubric but do not create it from the grading page.
- Do not exceed the maximum points for a criterion.
- Managers may have additional grade-override controls.
