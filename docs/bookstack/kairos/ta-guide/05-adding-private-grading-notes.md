# Adding private grading notes

## What this is for

Record an internal note for staff without showing it to the Student.

## How to do it

1. Open the Student submission in **Grading**.
2. Find **Private Note (not shown to student)**.
3. Enter the staff-only context.
4. Select **Save Draft** or **Release Grade** to save the grading work.
5. Reopen the submission to confirm the note remains.

![Private staff note beside student feedback](../screenshots/grading-workspace.png)

## Notes

- Private grading notes are visible only to authorized course staff.
- Put Student-facing guidance in **Feedback to Student**, not in the private note.
- Avoid unnecessary personal or sensitive comments.
