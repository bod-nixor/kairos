# Assigning rubrics

## What this is for

Add scoring criteria to an assignment so graders use a consistent structure.

## How to do it

1. Create a new assignment or open **Edit Assignment**.
2. Find **Grading Rubric**.
3. Add a criterion.
4. Enter its name and maximum points.
5. Repeat for each criterion.
6. Confirm the rubric total matches the assignment points.
7. Save the assignment and review the rubric on the assignment page.

## Notes

- Only Managers and Admins can define assignment rubrics.
- TAs score the rubric during grading.
- Keep criteria short, specific, and measurable.
- Review carefully before grades are released.
