# Inviting local-password users

## What this is for

Create a password account for a user who has been approved for local login.

## How to do it

1. Open **Admin**.
2. Find **Invite local account**.
3. Enter the full name, email, and username.
4. Choose the platform role.
5. Optionally choose a course and course access.
6. Select **Create account and send activation**.
7. Confirm that the account appears under **Pending accounts** until activated.

## Notes

- Only Admins can do this.
- Use a valid email address the user can access.
- The user creates their own password from the activation email.
- Do not create duplicate accounts for the same person.
