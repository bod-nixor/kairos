# Basic troubleshooting

## What this is for

Resolve common account, role, course, and activation issues before escalating.

## How to do it

1. Confirm the affected user, course, page, and exact message.
2. Ask the user to sign out and sign in with the correct account.
3. Check whether the account is still under **Pending accounts**.
4. Confirm the user's course enrollment or course-staff assignment.
5. Confirm the course is selected before changing its settings.
6. Retry the action once and record any visible error if it fails again.

## Notes

- Do not create a duplicate account to work around a missing role.
- Do not assign Admin when Manager or TA access is enough.
- Avoid deleting a course as a troubleshooting step.

## Troubleshooting

- **Activation problem:** resend from **Pending accounts**.
- **Course missing:** verify enrollment or staff assignment.
- **Wrong course role:** remove the incorrect assignment, then add the correct one.
- **Email not delivered:** verify the address and contact platform support with the visible error.
